# 帖子频道 API 文档

**基础地址（Base URL）：** `https://api.jade.run`

**鉴权方式：** 无（依赖请求来源校验）

**来源限制：** 请求头必须携带 `Origin` 或 `Referer`，且域名须为 `jade.run` 或 `*.jade.run`（如 `https://www.jade.run`），否则一律返回 `403 forbidden`。

---

## 1. 帖子列表

获取「官方活动」频道的帖子列表。

- **端点：** `GET /posts`
- **参数：** 无（频道 ID 已固定配置）
- **成功响应 `200 OK`：**

`{"count":2,"is_finish":1,"threads":[{"thread_id":"…","channel_id":"…","author_id":"…","title":"帖子标题","content":"帖子正文（段落文本/链接已递归提取为可读文本，多条内容以换行分隔）","date_time":"2026-03-04 12:00:00"}]}`

- **错误：**
  - `403` `forbidden` —— 来源不是 jade.run
  - `502` `upstream error` —— 上游 QQ 官方接口失败

---

## 2. 帖子详情

获取单帖完整内容。

- **端点：** `GET /posts/{thread_id}`
- **参数：** `thread_id`（路径参数，必填）
- **成功响应 `200 OK`：**

`{"thread_id":"…","channel_id":"…","author_id":"…","title":"帖子标题","content":"帖子正文…","date_time":"2026-03-04 12:00:00"}`

- **错误：**
  - `403` `forbidden` —— 来源不是 jade.run
  - `404` `not found` —— 帖子不存在或解析失败
  - `502` `upstream error` —— 上游 QQ 官方接口失败

---

## 调用示例

# 帖子列表（带 jade.run 域名为来源）
curl -s https://api.jade.run/posts -H "Origin: https://www.jade.run"

# 帖子详情
curl -s https://api.jade.run/posts/{thread_id} -H "Referer: https://example.jade.run/page"
